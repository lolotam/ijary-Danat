Primary action control; use for all clickable actions across landing, admin and portal.

```jsx
<Button>حفظ التغييرات</Button>
<Button variant="outline" size="sm">تعديل</Button>
```

Variants: default (black pill), gold (brand gold — use on dark/ink surfaces), destructive, outline (1.5px black), secondary, ghost, link. All buttons are pills. Sizes: default/sm/lg/icon.
