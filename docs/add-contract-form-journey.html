What happens on save · عند الحفظ

خط أنابيب التحقق
✓

Zod validation

Required fields and numeric limits (duration ≥ 1, due day 1–28, amounts ≥ 0).

التحقق من الحقول الإلزامية وحدود الأرقام.
!

End-date override reason

Manual end date rejected unless override reason is provided when end ≠ calculated.

لا يمكن تغيير تاريخ النهاية يدوياً بدون سبب.
⛔

Unit conflict check

Blocked if unit has a non-terminal contract. Edit excludes current contract id.

رفض الوحدة ذات عقد قائم غير نهائي.
＋

Create → invoice backfill

Saves contract then backfills monthly invoices from start through current month; may mark overdue.

إنشاء سجل الفواتير الشهرية حتى الشهر الحالي.
✎

Edit → update only

Updates existing contract; conflict check ignores this contract.

تحديث العقد واستثناؤه من فحص التعارض.
🔑

Permissions

Create / update / delete controlled by contracts permissions.

مرتبطة بصلاحيات المستخدم.
🗑

Delete rule

Only draft contracts can be deleted.

الحذف للمسودات فقط.

Create vs Edit · إضافة / تعديل

🟢 Create

  • Default duration 36 months
  • End = start + months − 1 day
  • Then backfill_contract_invoices
إضافة: مدة 36 شهراً، نهاية تلقائية، ثم فواتير تاريخية.

🔵 Edit

  • Loads existing values
  • Override if end already differs
  • Conflict ignores self
تعديل: تحميل القيم الحالية واستثناء العقد من التعارض.

Implementation note · ملاحظة تقنية

⚠

No explicit “end after start” on override

The form does not validate that end_date is after start_date when overriding — only that a reason is present when end differs from the calculated value.

لا يوجد تحقق صريح يمنع تاريخ نهاية قبل البداية عند التعديل اليدوي؛ المطلوب فقط سبب عند اختلاف التاريخ عن المحسوب.

What happens on save · عند الحفظ

✓

Zod validation

Name required. Category and lifecycle enums. Email empty or valid. Alternate contacts empty or a JSON array.

الاسم إلزامي؛ البريد صالح أو فارغ؛ جهات الاتصال JSON أو فارغة.
↔

Normalize empties

Optional strings (mobile, email, notes, …) become null when blank. Alternate contacts JSON is parsed before insert/update.

الحقول الاختيارية الفارغة تُحفظ كـ null بعد التنظيف.
＋

Create

Inserts tenant with company_id from current company. Code is generated by the backend. Defaults: category standard, lifecycle active, language ar, reminders on.

إنشاء مستأجر جديد مع الشركة الحالية والقيم الافتراضية.
✎

Edit

Updates existing tenant by id; form is prefilled from the selected row.

تحديث المستأجر الحالي بعد تحميل قيمه في النموذج.
🔑

Permissions

List requires tenants.read. Create / update / delete use matching tenant permissions. Import and export have separate gates.

العرض والإنشاء والتعديل والحذف والتصدير بصلاحيات منفصلة.
📎

After save

Dialog closes; list refreshes. Documents, contracts, and invoices live on the tenant detail page — not on this create form.

بعد الحفظ يُغلق الحوار؛ المستندات والعقود من صفحة التفاصيل.
🗑

Delete

Separate confirmation; requires delete permission. May fail if related records restrict delete.

حذف بتأكيد منفصل وصلاحية delete.

Defaults & enums · الافتراضيات

🟢 Default values

  • category: standard
  • lifecycle: active
  • preferred_language: ar
  • reminders_enabled: true
  • receipt_visible_to_tenant: false
  • tenant_portal_enabled: false
الافتراضي: قياسي · نشط · عربي · تذكيرات مفعّلة.

🔵 Enums

  • Category: vip, uncommitted, chronically_distressed, standard, custom
  • Lifecycle: active, inactive, contract_ended, blocked
  • Language: ar, en
التصنيفات وحالات دورة الحياة من قوائم الخيارات في النظام.

Implementation note · ملاحظة تقنية

ℹ

Alternate contacts must be JSON array text

The form stores alternate contacts as a string that must parse to a JSON array (or be empty). Invalid JSON fails Zod refine before save.

جهات الاتصال البديلة نص JSON لمصفوفة، أو فارغ. أي JSON غير صالح يفشل التحقق.
