⚔️ مصفوفة محاولات الهجوم الحديثة ودفاعات دانة المستقبل

💥 1. هجوم حجب الخدمة والفيضان المالي (DDoS & 10,000 Requests Flood)
محمي بالكامل (BLOCKED)
طريقة الهجوم (Hacker Vector)
توجيه شبكة أجهزة مخترقة (Botnet) لإرسال 10,000 طلب دفعة واحدة في ثانية واحدة لإسقاط الخادم وشل حركة السداد.
درع حماية دانة (Danat Shield)
طبقتان من الحماية:
1. Cloudflare Anycast: تمتص الهجوم على حافة الشبكة قبل أن يلمس سيرفر المنصة.
2. حارس النماذج (Rate Limiter): يقيد المحاولات العشوائية بـ 5 طلبات في الساعة لكل آي بي حقيقي.
الدليل البرمجي: src/lib/publicFormGuard.ts & Cloudflare Proxy (104.21.36.2)
🕵️ 2. استخراج وسرقة مفاتيح الـ API (API Key Sniffing & Secrets Theft)
معزول 100% (ZERO LEAK)
طريقة الهجوم (Hacker Vector)
فحص كود المتصفح (Inspect / DevTools) بحثاً عن كلمات مرور قاعدة البيانات أو مفاتيح KNET أو مفاتيح الإيميلات.
درع حماية دانة (Danat Shield)
عزل كامل (Air-Gapped Secrets): كود المتصفح يحتوي فقط على الـ Publishable Key العام.
مفاتيح الـ Service Role، كلمات مرور Postgres، وبوابات الدفع تعمل حصراً داخل بيئة السيرفر المعزولة في Docker.
الدليل البرمجي: src/lib/env.server.ts & src/integrations/supabase/client.server.ts
💉 3. حقن الأكواد الخبيثة وسرقة الجلسات (Cross-Site Scripting - XSS)
مطهّر ومحصّن (SANITIZED)
طريقة الهجوم (Hacker Vector)
كتابة سكريبت سرقة كوكيز <script>steal()</script> في نماذج التواصل، أسماء المستأجرين، أو التوقيعات.
درع حماية دانة (Danat Shield)
1. React Auto-Escaping: تشفير فوري لكافة المدخلات كنصوص مجردة غير قابلة للتنفيذ.
2. مكتبة DOMPurify الصارمة: قائمة بيضاء دقيقة لفلترة التوقيعات مع منع تام لأي كود تنفيذي.
الدليل البرمجي: src/lib/sanitizeHtml.ts & DOMPurify White-list Policy
🏢 4. التجسس بين المستأجرين وتعديل المعرّفات (Multi-Tenant IDOR Breach)
عزل نواة قاعدة البيانات (RLS ENFORCED)
طريقة الهجوم (Hacker Vector)
تعديل رقم الفاتورة أو العقد في الرابط من (101) إلى (102) لرؤية إيجارات أو بيانات مستأجر آخر في العمارة.
درع حماية دانة (Danat Shield)
سياسة أمان الصفوف (Row Level Security): حتى لو عرف المخترق رقم عقد جاره، قاعدة البيانات ترفض جلب السطر برمجياً؛ لأن الـ JWT Token الصادر للمستأجر لا يملك صلاحية إلا على شقته فقط.
الدليل البرمجي: PostgreSQL RLS Policies & auth.uid() Validation
🔌 5. محاولة اختراق منفذ قاعدة البيانات (Direct Port 5432 Attack)
المنفذ مغلق كلياً (CLOSED PORT)
طريقة الهجوم (Hacker Vector)
فحص الآي بي المباشر للسيرفر ومحاولة تخمين كلمة مرور PostgreSQL على المنفذ 5432 عبر الإنترنت.
درع حماية دانة (Danat Shield)
قاعدة البيانات معزولة داخلياً: المنفذ 5432 غير مربوط بالإنترنت العام إطلاقاً ومحصور داخل شبكة Docker الداخلية (172.19.0.6). ولا يمكن الدخول إلا بنفق SSH مشفر بمفتاح خاص.
الدليل: Docker HostConfig PortBindings: {} & Dokploy Private Bridge

🏰 استراتيجية الدفاع المتعدد الطبقات (Defense In Depth)

الطبقة 1
الدرع الخارجي: Cloudflare WAF & DDoS Shield
تصفية الترافيك المشبوه، صد هجمات الفيضان، وإخفاء عنوان IP السيرفر الحقيقي خلف 104.21.36.2.
الطبقة 2
بوابة السيرفر: Traefik Reverse Proxy & TLS Encryption
إجبار التشفير الكامل ببروتوكول HTTPS عبر شهادات Let's Encrypt وحظر الاتصالات المكشوفة.
الطبقة 3
تطبيق دانة: React UI & Application Form Guards
تطهير مدخلات المستخدمين (DOMPurify)، منع XSS، وتحديد عدد الطلبات في الساعة للنماذج العامة.
الطبقة 4
قلب المنظومة: PostgreSQL Row Level Security (RLS)
العزل التام لبيانات العقود والمستأجرين، ومنح الصلاحيات بناءً على التوكن المشفر والمطابقة الصارمة.

💼 الأسئلة التنفيذية الحاسمة لاجتماع الملاك

❓ هل بيانات عقود ومبالغ المستأجرين في أمان تام؟
نعم 100%. نظام دانة المستقبل يطبق قواعد الأمان المصرفي (RLS)، بحيث لا يمكن لأي مستأجر أو دخيل الاطلاع على عقد مستأجر آخر أو كشف حسابه.
❓ هل تستطيع روبوتات الهاكرز إسقاط الموقع أثناء التحصيل؟
مستحيل. الموقع محمي بشبكة Cloudflare العالمية التي تمتص هجمات ملايين الطلبات المتزامنة وتمنع انقطاع خدمة السداد عن المستأجرين.
❓ هل يمكن سرقة مفاتيح بوابات الدفع (KNET / MyFatoorah)؟
إطلاقاً. لا توجد أي مفاتيح دفع أو كلمات سر داخل كود المتصفح؛ كل المعاملات والتوثيق تتم داخل بيئة الخادم المشفرة فقط.
❓ ماذا يحدث إذا ترك أحد الموظفين جهازه مفتوحاً؟
جلسات الإدارة والموظفين تُقفل تلقائياً بعد مرور 6 ساعات، ويتم تجريد أي جهاز غير مصرح له من صلاحيات الدخول فوراً.
